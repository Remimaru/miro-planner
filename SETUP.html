🎯 Kanban Pro - Setup Guide

Follow these steps to set up your professional Miro Kanban board app.

1 Start Local Server

Choose one of these commands to start a local web server:

# Python 3 (Recommended)
python -m http.server 8000

# Node.js
npx http-server -p 8000

# PHP
php -S localhost:8000

Your app will be available at: http://localhost:8000

2 Create Miro App

Go to the Miro Developer Portal and create a new app:

Open Miro Developer Portal
  • Click "Create new app"
  • App Name: Kanban Pro
  • Description: Professional project management for Miro

3 Set Permissions

Required Permissions:
  • ✅ boards:read - Read board content
  • ✅ boards:write - Create and update items

4 Configure URLs

Set these URLs in your Miro app settings:

  • App URL: http://localhost:8000/
  • Web-plugin URL: http://localhost:8000/
⚠️ Note: For production, replace localhost:8000 with your hosting URL (e.g., GitHub Pages).

5 Install App

  1. In Miro app settings, click "Install app and get OAuth token"
  2. Select your team
  3. Click "Add" to authorize
✅ Success! Your app is now installed.

6 Use the App

  1. Open any Miro board
  2. Look for the Kanban Pro icon in the left sidebar
  3. Click the icon to open the panel
  4. Click "Initialize Board" to create columns
  5. Start adding tasks!

📚 Features

  • ✨ Professional App Cards with metadata
  • 📊 Three-column Kanban layout
  • 🖱️ Drag-and-drop from sidebar
  • 🔄 Auto-sorting algorithm
  • 📈 Real-time progress tracking
  • 🎯 Priority levels (High/Med/Low)
  • 👤 Assignee tracking

🚢 Production Deployment

For production use, host your app on:

  • GitHub Pages: Free static hosting
  • Netlify: Drag-and-drop deployment
  • Vercel: Git-based deployment
  • Firebase Hosting: Google Cloud hosting

Then update your Miro app URLs to point to your production URL.
